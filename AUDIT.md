## Область и метод

Проверены исходники `/root/jail`, рабочая копия `/opt/jail`, SQLite, `jail.service`, маршрут Caddy `/jail/` и HTTPS-ответы. Все проверки с изменением записей выполнялись в изолированных копиях приложения и БД; рабочую БД не меняли. Это аудит приложения jail и его интеграции с qr4you.ru, а не остальных сервисов на сервере.

## Итог

Приложение работает, но **не готово для реального производственного учёта на публичном адресе**. Основная причина — любой посетитель может выбрать роль, включая директора. Далее идут ошибки контроля состояния и целостности данных. На момент проверки рабочая БД содержит только стартовые записи: 3 заказчика, 3 модели, 2 работника, 6 операций; документов, заявок и записей зарплаты нет.

## Дополнительные риски

- `app.py:17` содержит тестовый запасной ключ сессий. В рабочей службе секрет задаётся через `/etc/jail.env` (права 600), поэтому текущая сессия не использует известный ключ. Лучше завершать запуск с ошибкой при отсутствии секрета.
- Маршрут ZIP-обновления без проверки пользователя (`app.py:1109–1147`) **отключён** в рабочем окружении: `/jail/update` отвечает 404. Если установить `JAIL_ENABLE_WEB_UPDATES=1`, произвольный посетитель сможет загрузить Python-код. В текущем виде включать эту переменную нельзя.
- `app.py:438–462`: пустой POST приёмки подтверждает все строки с количеством «отдано», поскольку отсутствующие поля по умолчанию заменяются этим значением.
- В `request_collect()` (`app.py:892–911`) цикл проходит и по строкам, добавленным складом на шаге 2. Повторное сохранение шага 1 может сбросить у них признак `placed`.
- Основной мониторинг проверяет только `127.0.0.1:8080/api/health`; отдельной проверки jail нет.

## Успешные проверки

- `jail.service` и Caddy активны; сайт доступен по HTTPS; `/jail/` перенаправляет на `/jail/login`.
- Страницы документов, справочников, обзора и расхождений вернули 200 под соответствующими ролями. На изолированной копии проверены основные страницы всех трёх ролей, ошибок 500 не было.
- Ссылки Flask формируются с префиксом `/jail`; cookie имеет `Secure`, `HttpOnly`, `Path=/jail`.
- `/jail/update`, `/jail/jail.db`, `/jail/app.py` возвращают 404. Caddy устанавливает `no-store` и `noindex` для раздела.
- `PRAGMA integrity_check` рабочей SQLite БД — `ok`; `PRAGMA foreign_key_check` не нашёл нарушений, хотя внешних ключей в схеме нет.
- Зависимости в виртуальном окружении проходят `pip check`.
