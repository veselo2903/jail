# Jail — учёт обувного производства

Версия приложения: **0.68**. Заказы, партии, заявки, поставки, материалы, дневная выработка и расчёт зарплаты. Стек: Flask, SQLite, Jinja2.

**Начать развёртывание:** [DEPLOY_FROM_ARCHIVE.md](DEPLOY_FROM_ARCHIVE.md). В папке [`ops/`](ops) лежат примеры настроек Caddy, systemd и переменных окружения.

Рабочие роли: директор, склад и производство. В текущем тестовом режиме вход по выбору роли, без пароля. Данные чистой установки пустые; семь производственных операций создаются автоматически.

Исходный код не содержит рабочую базу, фотографии моделей или секретный ключ. Для переноса существующих записей нужен отдельный снимок базы и папки `model-photos/`.

Подробная документация: [DEPLOYMENT.md](DEPLOYMENT.md), [карта производства и оплаты](docs/PRODUCTION_PAYROLL_MAP.md), [сокращённое меню](docs/MENU_IMPLEMENTATION_068.md).
